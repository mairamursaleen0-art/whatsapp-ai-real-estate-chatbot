# WhatsApp AI Real Estate Chatbot

An AI-powered WhatsApp chatbot built with **n8n** and **Green API** to automate real estate customer inquiries and provide instant, intelligent responses.

## Overview

This project demonstrates how AI and workflow automation can be used to handle real estate inquiries through WhatsApp.

The chatbot can understand customer messages, retrieve relevant property information from a knowledge base, and generate appropriate responses automatically.

## Key Features

* 🤖 AI-powered WhatsApp conversations
* 💬 Automated customer responses
* 🏠 Real estate property information handling
* 📚 Knowledge base integration using Google Docs
* 🔗 Green API integration for WhatsApp messaging
* ⚡ Workflow automation with n8n
* 🧠 AI-based response generation

## Workflow

**WhatsApp → Green API → n8n → AI Processing → Knowledge Base → Response → WhatsApp**

The workflow receives a customer's WhatsApp message through Green API, processes the request using AI, retrieves relevant information from the knowledge base, and sends the response back to the customer.

## Tools & Technologies

* **n8n**
* **Green API**
* **WhatsApp**
* **AI / LLM**
* **Google Docs**
* **Webhooks**
* **APIs**

## Use Cases

This chatbot can be adapted for:

* Property inquiries
* Property availability questions
* Property details and pricing
* Customer FAQs
* Lead qualification
* Initial customer support
* Real estate business communication

## Project Goal

The goal of this project is to demonstrate how AI-powered automation can improve customer communication for real estate businesses by handling repetitive inquiries automatically while providing fast and consistent responses.
